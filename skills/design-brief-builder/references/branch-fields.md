## 包装 Brief

适用于产品包装、系列包装、礼盒包装、包装升级。

| Field | Why it matters |
|---|---|
| 项目路线 | 单品路线 / 品牌或系列路线 / 待确认，影响后续表达策略 |
| 包装形式 | 盒、袋、瓶、罐、礼盒等，影响版面和结构 |
| SKU/规格 | 影响系列关系、正面信息层级、尺寸限制 |
| 包装结构素材 | 结构照片、刀模、尺寸、材质、工艺限制 |
| 货架/陈列/电商缩略图 | 影响远近观看距离、抓眼方式、信息优先级 |
| 正面必须露出 | 品名、品牌、口味、净含量、核心声明、合规信息 |
| 竞品/参考/禁忌 | 影响差异化和风格边界 |

素材状态必查项：

| Asset | Status options | Why it matters |
|---|---|---|
| 产品实拍/内容物照片 | 已提供 / 已提供预览，需高清源文件 / 缺失 / 待确认 | 影响食欲感、真实感、质地表达 |
| 样品/试吃/实物观察 | 已提供 / 缺失 / 待确认 | 影响口味、质地、高级感和文案准确性 |
| 当前包装/旧包装 | 已提供 / 缺失 / 待确认 | 影响延续、升级方向和不可丢失资产 |
| 包装结构/刀模/材质/工艺 | 已提供 / 缺失 / 待确认 | 影响落地、成本、版面空间 |
| 货架/陈列/竞品/参考 | 已提供 / 缺失 / 待确认 | 影响识别、差异化、渠道转化 |

## 海报 Brief

适用于产品海报、年节海报、活动主 KV。

先判断海报类型：

| Type | Focus |
|---|---|
| 产品海报 | 单个产品为什么值得买 |
| 年节海报 | 节日氛围、送礼理由、节令消费 |
| 活动主K | 活动主题、统一主视觉、延展适配 |

重点字段：

| Field | Why it matters |
|---|---|
| 传播目标 | 上新、促销、节日、品牌曝光、招商、私域转发等 |
| 使用平台 | 朋友圈、公众号、小红书、电商、线下屏、门店物料等 |
| 版位/尺寸 | 决定比例、信息密度和可读距离 |
| 主标题/主题 | 决定第一眼看见什么 |
| 活动机制 | 满减、折扣、赠品、限时、组合售卖等 |
| 视觉钩子 | 产品、人物、场景、节日符号、利益点符号 |
| CTA | 购买、扫码、咨询、到店、预约等 |
| 延展需求 | 横版、竖版、方图、系列图、门店物料 |

素材状态必查项：

| Asset | Status options | Why it matters |
|---|---|---|
| 产品图/主视觉素材 | 已提供 / 需高清源文件 / 缺失 / 待确认 | 决定画面主体是否可做 |
| 品牌素材 | 已提供 / 缺失 / 待确认 | 决定品牌一致性 |
| 活动机制与价格信息 | 明确 / 缺失 / 待确认 | 决定标题、利益点和 CTA |
| 平台尺寸/版位 | 明确 / 缺失 / 待确认 | 决定版式和信息量 |
| 节日/活动参考与禁忌 | 已提供 / 缺失 / 待确认 | 决定氛围边界和审美方向 |

## 详情页 Brief

适用于电商详情页、产品销售页、私域销售长图。

重点字段：

| Field | Why it matters |
|---|---|
| 平台/渠道 | 淘宝、天猫、抖音、小红书、私域、团购等，影响规则和阅读习惯 |
| 首屏策略 | 首屏必须立刻说明最强购买理由 |
| 页面模块 | 首屏、卖点、证据、场景、规格、背书、对比、售后等 |
| 卖点证据链 | 每个卖点都要对应事实、图片、数据或背书 |
| 用户疑虑 | 价格、品质、口味、效果、规格、适用人群、售后等 |
| 对比/背书 | 竞品对比、检测证明、资质、评价、专家/达人背书 |
| 转化路径 | 加购、下单、咨询、领券、组合购买 |
| 平台限制 | 尺寸、禁词、合规、移动端阅读节奏 |

素材状态必查项：

| Asset | Status options | Why it matters |
|---|---|---|
| 产品图/包装图/细节图 | 已提供 / 需高清源文件 / 缺失 / 待确认 | 支撑首屏和卖点模块 |
| 场景图/使用图 | 已提供 / 缺失 / 待确认 | 支撑使用场景和代入感 |
| 证书/检测/资质/评价 | 已提供 / 缺失 / 待确认 | 支撑信任和证据链 |
| 规格/价格/活动/售后 | 明确 / 缺失 / 待确认 | 影响购买判断 |
| 竞品详情页/参考/禁忌 | 已提供 / 缺失 / 待确认 | 影响模块顺序和差异化 |

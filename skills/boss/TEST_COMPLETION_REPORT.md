## 6️⃣ 故障排查

如果实际测试中发现问题：

### 检查清单

1. **验证修复是否生效**
   ```bash
   cd ~/.openclaw
   python3 skills/boss/verify_fix.py
   ```

2. **查看 gateway 日志**
   ```bash
   openclaw logs | grep -i "topic\|thread\|subagent" | tail -50
   ```

3. **查看 subagent session**
   ```bash
   ls -lt agents/strategy-shared/sessions/ | head -5
   cat agents/strategy-shared/sessions/[最新session].jsonl | jq 'select(.type=="message")'
   ```

4. **检查任务描述**
   - 任务中是否包含「交付模式：静默回传」标记
   - Subagent 是否理解了静默交付指令

### 常见问题

**问题 1**：Subagent 仍然创建新话题
- **原因**：Subagent 没有遵循静默交付规则
- **解决**：检查 AGENTS.md 是否包含交付规则，可能需要重启 gateway

**问题 2**：Main 没有转发 subagent 结果
- **原因**：Main 没有接收到 subagent 的回传
- **解决**：检查 subagent 是否正确回传了路径和摘要

**问题 3**：图片投送创建新话题
- **原因**：Design agent 使用了错误的参数
- **解决**：检查是否使用 `path` 参数，不传 `target` 和 `threadId`

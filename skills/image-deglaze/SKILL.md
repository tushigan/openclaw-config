# Image Deglaze（参考图高清重绘）

## ⚠️ 重要定位说明

**本 skill 的本质是”AI 理解参考图后重新生成”，不是”像素级去噪”。**

### 适用场景

✅ **适合：**
- 基于低质量草图/原型，生成高清成品
- 提升画质，同时允许 AI 优化细节、调整风格
- 将模糊/低分辨率图片重绘为高清版本（允许内容微调）
- 风格化重绘（如照片转插画、插画风格升级）

❌ **不适合：**
- 完全保持原图内容（IP、文字、排版）的去包浆需求
- 精确保留设计稿的所有元素
- 只想去噪/锐化而不改变任何内容

**如果用户明确要求”完全保持原图内容”，应推荐使用：**
- Real-ESRGAN（本地 AI 超分辨率工具）
- Magnific AI / Clipdrop（在线超分辨率服务）
- 传统图像处理（降噪 + 锐化）

### 技术限制

图生图（gpt-image2-gen）的工作原理：
1. AI 理解参考图的”语义”（这是什么、什么风格）
2. 根据 prompt 重新生成
3. **无法做到像素级精确保持**

因此：
- ✅ 可以保持大致构图和风格
- ✅ 可以提升整体质感和清晰度
- ❌ 会改变细节（文字、IP 形象、精确排版）
- ❌ 无法单纯”去噪”而完全不改内容

## 工作流程

### 1. 明确用户需求

**首先判断：用户是否要求"完全保持原图内容"？**

如果用户说：
- "去包浆但不要改变 IP、文字、排版"
- "保持原图所有设计元素"
- "只去噪不改内容"

→ **停止使用本 skill**，推荐用户使用：
- Real-ESRGAN（本地超分辨率）
- Clipdrop / Magnific AI（在线超分辨率）

如果用户说：
- "提升画质，可以优化细节"
- "基于这个草图生成高清版"
- "重绘成更清晰的版本"

→ **继续使用本 skill**

### 2. 分析参考图

理解参考图的核心要素：

**构图分析要点：**
1. **主体识别**：主要元素是什么？位置在哪？
2. **元素布局**：各元素的相对位置和空间关系
3. **色调风格**：整体色彩倾向（暖色/冷色、饱和度、明度）
4. **光影特点**：光源方向、光影层次、氛围
5. **比例尺寸**：原图的宽高比（16:9、9:16、1:1 等）

**输出格式示例：**
```
主体：[描述主要元素]
布局：[描述元素位置关系]
色调：[描述色彩风格]
光影：[描述光影特点]
比例：[宽x高，如 1536x2048]
```

### 3. 构建重绘 Prompt

**核心策略：描述"目标效果"，而不是"参考图特征"**

#### Prompt 构建模板

```
[场景/主题描述]，参考图用于构图和风格方向

构图布局（参考原图）：
- [主要元素位置]
- [空间关系]
- [比例和排版]

高清重绘要求：
- [主体细节描述]
- [材质质感要求]
- [光影效果]
- [色调要求]

风格：高清商业级，细节丰富，边缘清晰
```

#### 关键技术点

**A. 控制改动幅度**
- 构图锁定：明确列出所有元素的位置
- 适度自由：允许 AI 优化细节和质感
- 平衡点：在"保持大致构图"和"提升质量"之间找平衡

**B. 强调质感和细节**
- 使用具体的形容词：清晰、分明、细腻、光泽、纹理、层次
- 针对每个元素描述具体的质感要求
- 避免笼统描述

**C. 正向描述优先**
- ✅ 使用：高清晰度、丰富细节、真实质感、清晰层次
- ⚠️ 少用否定词（AI 可能误解）

**D. 色调控制**
- 明确色彩倾向（暖色/冷色）
- 指定饱和度（高饱和/低饱和/淡雅）
- 描述整体氛围

**E. 比例保持**
- 确保输出尺寸与原图比例一致
- 常见比例：16:9 (1920x1080)、9:16 (1080x1920)、1:1 (1024x1024)、3:4 (1536x2048)

**F. Prompt 长度控制**
- 控制在 150-200 字符以内
- 过长会分散 AI 注意力
- 每次迭代替换而非累积

### 4. 执行图生图生成

使用 `gpt-image2-gen` skill 执行生成：

```bash
# 基本用法
python3 /path/to/gpt-image2-gen/scripts/generate.py \
  --prompt-file prompt.txt \
  --reference original.jpg \
  --size 1920x1080 \
  --output result.png
```

**注意事项：**
- 参考图会自动压缩（默认启用），无需手动处理
- 如果原图尺寸过大，选择接近的标准尺寸
- 生成时间通常 30-60 秒（取决于分辨率）
- 默认分辨率 1920x1080，按需调整

### 5. 评估结果并迭代

生成完成后，对比原图和新图：

**评估维度：**
1. **画质改善**：细节是否更清晰？质感是否更好？
2. **构图保持**：主要元素位置是否大致保持？
3. **色调准确**：色彩是否符合预期？
4. **内容偏差**：有哪些细节被改变了？可接受吗？

**常见问题及调整：**

| 问题 | 原因 | 调整方案 |
|------|------|----------|
| 色彩过重/过淡 | 色调描述不准确 | 明确"淡雅""低饱和度"或"饱和""鲜艳" |
| 比例错误 | 尺寸设置错误 | 检查原图比例，调整 --size 参数 |
| 构图偏移 | 元素描述不够具体 | 增加元素位置的详细描述 |
| 内容改变太多 | prompt 过于自由 | 增加构图锁定描述，或**改用超分辨率工具** |
| 细节仍然模糊 | 质感描述不够强 | 增强质感关键词 |
| 风格偏离 | 风格描述冲突 | 检查 prompt 中的风格关键词 |

**迭代策略：**
- 第一次生成：验证大方向是否正确
- 第二次生成：微调色调和细节强度
- 如果多次迭代内容偏差仍大 → **建议改用专业超分辨率工具**

## 使用场景示例

### 场景 1：草图转高清成品（推荐）

**适用：**手绘草图、原型图转高清商业作品

```
商业海报设计，参考草图构图

构图：上方大标题区，中央产品展示，底部文案区
主体：产品居中，周围装饰元素
质感：高清商业摄影级，细节丰富，专业光影
```

### 场景 2：低质量图片高清化（有风险）

**适用：**模糊/低分辨率图片重绘

**风险：**细节会被 AI 重新想象，不一定准确

```
[描述图片内容]，参考图用于构图

保持大致布局和风格
高清重绘，细节丰富，边缘清晰
```

### 场景 3：风格化重绘（推荐）

**适用：**改变风格的同时提升质量

```
[场景描述]，参考图提供构图，转换为[目标风格]

构图参考原图
风格：[目标风格描述]
质感：高清细腻，专业级质量
```

## 不推荐使用的场景

❌ **确定版设计稿去包浆** → 用 Real-ESRGAN / Magnific AI
❌ **带重要文字内容的海报** → 文字会改变，用超分辨率工具  
❌ **精确的 IP 形象** → 形象细节会变化，用超分辨率工具
❌ **只想去噪不改内容** → 用传统图像处理或超分辨率

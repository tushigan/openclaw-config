# Image Deglaze（图片去包浆）

## 核心原理

**电子包浆**是图生图多次迭代后的常见问题：每次生成都会损失细节、降低锐度、平滑质感，最终导致画面模糊、缺乏真实感。

**去包浆方法**：用包浆图作为参考图，通过精心设计的 prompt 进行全图重新生成。关键是在保持构图的同时，通过 prompt 引导模型重建细节和质感。

## 工作流程

### 1. 诊断包浆特征

分析图片，识别包浆表现：

**视觉特征检查清单：**
- [ ] 整体模糊，锐度不足
- [ ] 质感平淡，缺少纹理细节
- [ ] 光影过渡过于平滑，缺少层次
- [ ] 边缘柔和，轮廓不清晰
- [ ] 色彩饱和度降低或过度饱和
- [ ] 细节元素（文字、纹理、材质）模糊不清

**严重程度评估：**
- **轻度包浆**：细节略微模糊，但主体清晰
- **中度包浆**：明显质感损失，细节模糊
- **重度包浆**：严重模糊，几乎无法辨识细节

### 2. 分析原图构图

在构建去包浆 prompt 前，必须先分析原图：

**构图分析要点：**
1. **主体识别**：主要元素是什么？位置在哪？
2. **元素布局**：各元素的相对位置和空间关系
3. **色调风格**：整体色彩倾向（暖色/冷色、饱和度、明度）
4. **光影特点**：光源方向、光影层次、氛围
5. **比例尺寸**：原图的宽高比（16:9、9:16、1:1 等）

**输出格式示例：**
```
主体：[描述主要元素]
布局：[描述元素位置关系]
色调：[描述色彩风格]
光影：[描述光影特点]
比例：[宽x高，如 1536x2048]
```

### 3. 构建去包浆 Prompt

根据分析结果，按以下结构构建 prompt：

#### Prompt 构建模板

```
[场景/主题描述]，保持参考图构图和元素布局

主体：[主要元素的详细描述，强调质感和细节]

场景元素：
- [元素1]：[具体质感描述]
- [元素2]：[具体质感描述]
- [元素3]：[具体质感描述]
...

光影：[光影描述，强调层次感]
色调：[色彩描述，明确饱和度和明度]
风格：高清晰度，丰富细节，真实质感，专业摄影
```

#### 关键技术点

**A. 锁定构图和元素**
- 明确列出所有元素的位置和布局
- 使用"保持参考图构图和元素布局"锁定整体结构
- 对于有文字的图片，必须列出所有文字内容和位置

**B. 强调质感和细节**
- 针对每个元素描述具体的质感要求
- 使用具体的形容词：清晰、分明、细腻、湿润、光泽、纹理、层次
- 避免笼统描述，要具体到材质特征

**C. 避免包浆关键词**
- ✅ 使用：高清晰度、丰富细节、真实质感、专业摄影、清晰层次
- ❌ 避免：柔和、梦幻、朦胧、柔焦、模糊、平滑

**D. 色调控制**
- 明确色彩倾向（暖色/冷色）
- 指定饱和度（高饱和/低饱和/淡雅）
- 如果原图色彩偏淡，强调"淡雅""低饱和度""柔和色调"
- 如果原图色彩浓郁，强调"饱和""鲜艳""对比强烈"

**E. 比例保持**
- 确保输出尺寸与原图比例一致
- 常见比例：16:9 (1920x1080)、9:16 (1080x1920)、1:1 (1024x1024)、3:4 (1536x2048)

### 4. 执行图生图生成

使用 `gpt-image2-gen` skill 执行生成：

```bash
# 基本用法
gpt-image2-gen --prompt-file prompt.txt --reference original.png --size 1536x2048 --output restored.png

# 或直接调用 skill
使用 gpt-image2-gen skill，参考图为 [原图路径]，prompt 为 [去包浆 prompt]，尺寸为 [原图尺寸]
```

**注意事项：**
- 参考图会自动压缩（默认启用），无需手动处理
- 如果原图尺寸过大，选择接近的标准尺寸
- 生成时间通常 30-60 秒

### 5. 评估结果并迭代

生成完成后，对比原图和新图：

**评估维度：**
1. **画质改善**：细节是否更清晰？质感是否更真实？
2. **构图保持**：元素位置是否保持一致？
3. **色调准确**：色彩是否符合预期？是否过重或过淡？
4. **比例正确**：尺寸比例是否与原图一致？

**常见问题及调整：**

| 问题 | 原因 | 调整方案 |
|------|------|----------|
| 色彩过重/过淡 | 色调描述不准确 | 在 prompt 中明确"淡雅""低饱和度"或"饱和""鲜艳" |
| 比例错误 | 尺寸设置错误 | 检查原图比例，调整 --size 参数 |
| 构图偏移 | 元素描述不够具体 | 增加元素位置的详细描述 |
| 细节仍然模糊 | 质感描述不够强 | 增强质感关键词，避免包浆词汇 |
| 风格偏离 | 风格描述冲突 | 检查 prompt 中是否有"柔和""梦幻"等包浆词 |

**迭代策略：**
- 第一次生成：验证构图和整体方向
- 第二次生成：微调色调和细节强度
- 通常 1-2 次迭代即可达到满意效果

## 场景化 Prompt 模板

不同类型的图片需要不同的去包浆策略。参考 [references/prompt-templates.md](references/prompt-templates.md) 获取以下场景的详细模板：

- **产品图**：强调材质质感、光泽、纹理
- **人物图**：强调皮肤质感、毛发细节、服装纹理
- **场景图**：强调空间层次、光影对比、环境细节
- **食物图**：强调食材质感、色泽、新鲜度
- **文字海报**：强调文字清晰度、排版精准度

## 最佳实践

1. **先诊断再行动**：不要跳过包浆特征分析，这决定了 prompt 的侧重点
2. **构图分析要详细**：元素越多，描述越要精确
3. **质感描述要具体**：避免"好看""精美"等模糊词汇
4. **色调控制要明确**：色彩偏差是最常见的问题
5. **保持比例一致**：比例错误会破坏整体效果
6. **迭代要有针对性**：每次调整只改一个维度

## 局限性

- **无法恢复完全丢失的信息**：如果原图某些区域已经完全模糊，去包浆只能重建，不能还原
- **文字可能变化**：即使在 prompt 中指定文字内容，生成的文字可能与原图略有差异
- **风格可能漂移**：如果原图风格非常独特，可能难以完全保持
- **需要多次迭代**：复杂图片可能需要 2-3 次调整才能达到最佳效果

## 故障排除

**问题：生成失败或超时**
- 检查参考图文件是否存在
- 检查网络连接
- 尝试减小图片尺寸

**问题：生成结果与原图差异过大**
- 增加构图锁定描述的详细程度
- 在 prompt 开头强调"严格保持参考图构图"
- 考虑使用更高的参考图权重（如果工具支持）

**问题：文字内容错误**
- 在 prompt 中用引号明确标注文字内容
- 使用"exactly"等强调词
- 考虑后期手动修正文字

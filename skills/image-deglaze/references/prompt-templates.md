## 产品图去包浆

### 特点
- 强调材质质感（金属、塑料、布料、玻璃等）
- 突出产品细节（纹理、接缝、logo、按钮）
- 保持光泽和反光效果
- 色彩准确度要求高

### 模板结构

```
[产品名称] 产品摄影，保持参考图构图和元素布局

主体：[产品描述]，[材质质感]，[表面特征]，[细节特征]

场景元素：
- 背景：[背景描述，强调质感]
- 道具1：[道具描述，具体材质]
- 道具2：[道具描述，具体材质]

光影：[光源描述]，[反光描述]，清晰的高光和阴影，层次分明
色调：[色彩倾向]，[饱和度]，色彩准确
风格：高清晰度，丰富细节，真实质感，专业产品摄影
```

### 实战案例：千层面包海报

**原图问题：**
- 面包层次模糊，酥皮纹理不清
- 黄油、书本、纸张质感平淡
- 整体偏柔和，锐度不足

**去包浆 Prompt：**
```
游忆佳族黄油千层面包中考加油海报，保持参考图构图和元素布局

主体：切片黄油千层面包，清晰可见的酥皮层次，每一层都分明，边缘浅金黄（不要过度烘烤，不要焦黄），表面有自然的烘焙纹理和柔和光泽

场景元素：
- 白色餐巾布，能看到织物纹理，自然褶皱
- 黄油块，湿润有光泽，细腻质地，放在小碟子上
- 书本堆叠，清晰的书脊文字"中考必胜 金榜题名"，纸张有真实纹理
- 学士帽、钢笔、手写纸条"中为加油"
- 左上角游忆佳族品牌 logo
- 中部书法标题"千层努力 终见光芒"
- 右上角"中考加油"

光影：柔和自然光，有层次感，不过度平滑，清晰的阴影边界
色调：淡雅温暖，米黄色、奶油色、浅金黄色，低饱和度
风格：高清晰度，丰富细节，真实质感，专业产品摄影
```

**关键调整点：**
- 第一版色彩过重 → 增加"淡雅""低饱和度""不要过度烘烤"
- 比例错误 → 从 1536x2048 (3:4) 改为 1440x2560 (9:16)

### 常见产品类型关键词

**电子产品：**
- 金属：磨砂质感、阳极氧化、CNC 切割边缘、细腻拉丝纹理
- 屏幕：高清显示、轻微反光、清晰像素
- 按钮：清晰轮廓、细微凹陷、触感真实

**服装产品：**
- 布料：清晰织物纹理、自然褶皱、柔软垂感
- 缝线：清晰可见的针脚、整齐排列
- 标签：清晰的文字和 logo

**化妆品：**
- 包装：光滑表面、精致印刷、清晰文字
- 质地：膏体光泽、液体透明度、粉末细腻度
- 容器：玻璃透明感、塑料光泽、金属质感

## 人物图去包浆

### 特点
- 强调皮肤质感（毛孔、细纹、光泽）
- 突出毛发细节（发丝、眉毛、睫毛）
- 保持眼神清晰度
- 服装纹理和褶皱

### 模板结构

```
[人物描述] 人像摄影，保持参考图构图和姿态

主体人物：[性别/年龄/特征]，[皮肤质感]，[五官细节]，[发型描述]

服装：[服装描述]，[材质质感]，[褶皱细节]

表情：[表情描述]，眼神清晰有神，细节丰富

光影：[光源描述]，面部光影层次分明，自然过渡
色调：[肤色描述]，[整体色调]
风格：高清晰度，真实皮肤质感，丰富细节，专业人像摄影
```

### 关键词库

**皮肤质感：**
- 健康光泽、细腻毛孔、自然肤色、真实质感
- 避免：磨皮、柔焦、梦幻、朦胧

**毛发细节：**
- 清晰发丝、自然光泽、层次分明、细节丰富
- 避免：模糊、柔和、平滑

**眼神：**
- 眼神清晰、瞳孔细节、眼白分明、睫毛清晰
- 避免：朦胧、柔和

**服装：**
- 清晰织物纹理、自然褶皱、材质真实、细节丰富

## 场景图去包浆

### 特点
- 强调空间层次（前景、中景、远景）
- 突出光影对比
- 保持环境细节（建筑、植物、天空）
- 氛围营造

### 模板结构

```
[场景描述]，保持参考图构图和视角

前景：[前景元素]，[质感细节]
中景：[中景元素]，[质感细节]
远景：[远景元素]，[质感细节]

光影：[光源描述]，[光影层次]，清晰的明暗对比
色调：[色彩氛围]，[饱和度]
天气：[天气状况]，[大气透视]
风格：高清晰度，丰富细节，真实质感，专业风光摄影
```

### 关键词库

**空间层次：**
- 前景清晰、中景过渡、远景虚化（如需要）
- 空间深度、透视准确、层次分明

**光影：**
- 清晰阴影边界、光影对比强烈、层次丰富
- 避免：过度平滑、柔和过渡

**环境细节：**
- 建筑：清晰线条、材质纹理、窗户反光
- 植物：清晰叶片、枝干纹理、自然色彩
- 天空：云层细节、色彩过渡、大气透视

## 食物图去包浆

### 特点
- 强调食材质感（湿润、光泽、纹理）
- 突出色泽和新鲜度
- 保持细节（颗粒、纹理、汁水）
- 诱人的视觉效果

### 模板结构

```
[食物名称] 美食摄影，保持参考图构图和摆盘

主体：[食物描述]，[质感描述]，[色泽描述]，[细节描述]

配菜/装饰：
- [配菜1]：[质感描述]
- [配菜2]：[质感描述]

餐具/背景：[餐具描述]，[背景描述]

光影：[光源描述]，食物表面有自然光泽和高光，清晰的阴影
色调：[色彩描述]，色彩鲜艳饱满，诱人食欲
风格：高清晰度，丰富细节，真实质感，专业美食摄影
```

### 关键词库

**食材质感：**
- 湿润光泽、细腻纹理、颗粒分明、汁水饱满
- 新鲜、诱人、真实

**色泽：**
- 色彩鲜艳、饱和度高、对比强烈
- 金黄、翠绿、鲜红（根据食材）

**细节：**
- 清晰纹理、颗粒可见、表面细节丰富
- 避免：模糊、柔和、平滑

## 文字海报去包浆

### 特点
- 强调文字清晰度和可读性
- 保持排版精准度
- 突出设计元素细节
- 色彩准确度要求高

### 模板结构

```
[海报主题] 海报设计，保持参考图构图和排版

文字内容（必须精确列出）：
- 标题："[精确文字内容]"，位置：[位置描述]
- 副标题："[精确文字内容]"，位置：[位置描述]
- 正文："[精确文字内容]"，位置：[位置描述]

设计元素：
- [元素1]：[描述]，清晰细节
- [元素2]：[描述]，清晰细节

背景：[背景描述]，[质感描述]

光影：[光影描述]
色调：[色彩描述]，色彩准确
风格：高清晰度，文字清晰可读，设计元素细节丰富，专业平面设计
```

### 关键注意事项

1. **文字内容必须用引号标注**，并使用 "exactly" 强调
2. **列出所有文字**，包括小字和装饰性文字
3. **描述文字位置**，使用"左上角""中部""右下角"等明确位置词
4. **强调清晰度**："文字清晰可读""边缘锐利""不模糊"

### 示例

```
品牌海报设计，保持参考图构图和排版

文字内容（精确）：
- 主标题："创新未来"，位置：画面中央偏上，大号粗体
- 副标题："科技改变生活"，位置：主标题下方，中号字体
- 品牌名："TechVision"，位置：左上角，小号字体
- 日期："2026.06.01"，位置：右下角，小号字体

设计元素：
- 科技感线条，清晰锐利，蓝色渐变
- 几何图形装饰，边缘清晰，层次分明
- 品牌 logo，细节清晰，色彩准确

背景：深蓝色渐变背景，平滑过渡，细微纹理

光影：柔和光效，不过度模糊
色调：蓝色主调，高饱和度，对比强烈
风格：高清晰度，文字清晰可读，设计元素细节丰富，现代科技风格
```

## 通用调整技巧

### 色调调整

**问题：色彩过重**
```
调整前：温暖色调，金黄色
调整后：淡雅温暖色调，浅金黄色，低饱和度
```

**问题：色彩过淡**
```
调整前：色彩鲜艳
调整后：色彩饱和鲜艳，对比强烈，高饱和度
```

### 质感调整

**问题：仍然模糊**
```
调整前：清晰细节
调整后：极高清晰度，丰富细节，每个元素都清晰可见，纹理细腻，边缘锐利
```

**问题：过度锐化**
```
调整前：高清晰度
调整后：自然清晰度，细节丰富但不过度锐化，真实质感
```

### 光影调整

**问题：光影过平**
```
调整前：柔和光影
调整后：清晰光影层次，明暗对比分明，阴影边界清晰，高光细节丰富
```

**问题：光影过硬**
```
调整前：清晰光影
调整后：柔和自然光，光影层次丰富，过渡自然但不过度平滑
```

### 构图调整

**问题：元素位置偏移**
```
在 prompt 开头增加：严格保持参考图构图，所有元素位置与参考图完全一致
```

**问题：元素缺失**
```
在场景元素部分详细列出每个元素，包括小元素和背景元素
```

## 快速检查清单

在发送 prompt 前，检查以下要点：

- [ ] 是否明确了"保持参考图构图和元素布局"？
- [ ] 是否列出了所有主要元素？
- [ ] 是否为每个元素描述了具体质感？
- [ ] 是否避免了包浆关键词（柔和、梦幻、朦胧）？
- [ ] 是否明确了色调倾向和饱和度？
- [ ] 是否指定了正确的尺寸比例？
- [ ] 是否强调了"高清晰度、丰富细节、真实质感"？
- [ ] 对于文字海报，是否精确列出了所有文字内容？

## 进阶技巧

### 分层描述法

对于复杂图片，按层次描述：

```
第一层（最前景）：[元素]，[质感]
第二层（中景）：[元素]，[质感]
第三层（背景）：[元素]，[质感]
```

### 对比强调法

通过对比强调想要的效果：

```
不要：模糊、柔和、朦胧
要：清晰、锐利、细节丰富
```

### 材质库引用法

引用真实材质作为参考：

```
金属质感：如不锈钢的磨砂质感
布料质感：如亚麻布的粗糙纹理
皮肤质感：如真实人像摄影的自然肤质
```

### 摄影术语法

使用专业摄影术语提升效果：

```
- 景深：浅景深、大光圈虚化
- 光源：柔光箱、侧光、逆光
- 色温：暖色调 3200K、冷色调 5600K
- 风格：商业摄影、时尚摄影、纪实摄影
```

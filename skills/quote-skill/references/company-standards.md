# Company Standards

## Required behaviors

- Keep company standards inside this skill directory.
- Treat prices as human-entered values.
- Preserve proposal-style structure for HTML/PDF output.

## Required sections

- 标题
- 副标题
- 项目概述
- 阶段规划
- 分阶段服务表
- 汇总说明
- 备注 / 排除项

## Sample-aligned layout guidance

- Proposal-style HTML/PDF output should follow the same narrative rhythm as `assets/samples/danfu-example.html`.
- Prefer section order: 概述 -> 阶段规划 -> 分阶段服务表 -> 汇总 -> 备注.
- Keep responsibility fields explicit when they are available.

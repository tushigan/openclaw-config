# Pressure Scenarios

Use these scenarios when refining or testing the skill.

## Scenario 1: Too Few Product Photos

User asks for a premium product image but uploads only one filtered mobile photo.

Expected behavior:

- request more angles
- explain the risk clearly
- do not skip the risk confirmation gate

## Scenario 2: Structure-Sensitive Product

User requests a filled bakery item or layered snack but provides only exterior photos.

Expected behavior:

- flag missing cross-section evidence
- ask for cut-open or internal-detail photos
- record whether the user accepts structure guesswork

## Scenario 3: Strong Style Reference, Weak Product Evidence

User provides a beautiful reference shot but weak product evidence.

Expected behavior:

- keep the product facts above style imitation
- explain that style can guide lighting and composition, not product anatomy

## Scenario 4: Revision Without Re-Intake

User dislikes the first generation but wants the same product, same structure, and a different lighting mood.

Expected behavior:

- preserve the locked product profile
- preserve product references
- update creative direction or prompt package only

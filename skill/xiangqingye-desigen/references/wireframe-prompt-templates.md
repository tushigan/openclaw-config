# 黑白手稿提示词模板

## 使用说明

这些模板用于 Step 3 黑白手稿生成。使用时：
1. 替换 `{{...}}` 占位符为实际内容
2. 通过 `gpt-image2-gen` skill 的 `generate.py` 调用
3. 尺寸必须先用 `validate_dimensions.py` 验证

## 产品事实注入格式

在调用前，从 `lock_product_facts.py` 生成的 JSON 中提取关键字段，填入 `{{PRODUCT_FACTS_INJECTION}}`：

```
产品：{{brand}} {{product}}（{{category}}）
结构：{{structure.description}}，{{layers}}层结构
{{#if is_coated}}表面有涂层{{/if}}
{{#if is_molten}}切面需展示流心效果{{/if}}
{{#if cross_section_needed}}需要横截面展示{{/if}}
压纹：{{emboss.description}}
口味：{{flavors 列表}}
{{#if main_flavor}}主推口味：{{main_flavor}}{{/if}}
{{#if packaging_required}}包装必须出现在页面中{{/if}}
{{#if logo_locked}}品牌 LOGO 必须精确还原，不可重绘{{/if}}
```

## 精度自检

手稿生成后，按以下标准自检：

| 检查项 | 合格标准 |
|--------|----------|
| 线稿精度 | 黑线清晰，不是几个框+几条线 |
| 信息层级 | 主标题、副标题、正文有明显大小/粗细区分 |
| 图文关系 | 产品/文字/装饰元素位置关系明确 |
| 中文排版 | 有真实中文字，不是英文占位 |
| 过渡自然 | 上下段之间有视觉连续性，不是拼贴感 |
| 完成度 | 用户可以判断"这段详情页顺不顺" |

任一项不合格，应重新生成。

### 2. 强制品牌档案检查机制 ✅

**问题**：Agent 可以跳过品牌档案检查，直接执行任务，导致品牌信息无法积累。

**修复**：

#### 2.1 创建强制检查脚本

**文件**：`skills/boss/scripts/ensure_brand_profile.py`（新增）

**功能**：
- 检查品牌档案是否存在
- 从任务描述自动提取品牌信息（行业、定位、受众、调性）
- 支持自动创建或提示用户确认
- 返回标准化的 JSON 结果

**使用方式**：
```bash
# 检查品牌档案
python3 ensure_brand_profile.py --brand "品牌名" --json

# 自动创建（从任务描述提取信息）
python3 ensure_brand_profile.py \
  --brand "品牌名" \
  --client "客户名" \
  --extract-from "任务描述文本" \
  --auto-create \
  --json
```

#### 2.2 更新所有 Agent 的 AGENTS.md

**修改文件**：
- `workspace-design/AGENTS.md` - 新增 1.2.6 节
- `workspace-strategy/AGENTS.md` - 新增 0.05.5 节
- `workspace-copywriter/AGENTS.md` - 新增 1.0.5 节
- `workspace/AGENTS.md` - 新增 1.0.7 节

**规则内容**：
```markdown
#### 品牌任务强制档案检查（⚠️ 强制执行，不可跳过）

**适用范围**：所有涉及品牌的任务

**执行时机**：任务开始前

**强制检查流程**：
1. 识别品牌名称
2. 调用 ensure_brand_profile.py
3. 处理检查结果：
   - 档案已存在 → 继续执行
   - 档案不存在 → 暂停任务，提示用户创建

4. 任务完成后自动回写新信息

**违反后果**：
❌ 不允许跳过档案检查
❌ 不允许"为了快速出结果"而绕过建档
```

**测试验证**：

## 🚀 使用方式

### Agent 自动执行

所有 Agent 在执行品牌任务时，会自动：

1. 检查品牌档案是否存在
2. 如不存在，提示用户创建
3. 从任务描述提取品牌信息
4. 创建或更新档案
5. 使用档案信息执行任务

### 用户无需操作

当用户说："帮我做一个 XX 品牌的海报"时：
- ✅ 系统自动检查 XX 品牌档案
- ✅ 档案不存在时自动提示
- ✅ 用户确认后自动创建
- ✅ 后续任务自动使用品牌档案

### 脚本手动调用

```bash
# 检查品牌档案
python3 ensure_brand_profile.py --brand "品牌名" --json

# 自动创建（从任务描述提取）
python3 ensure_brand_profile.py \
  --brand "品牌名" \
  --extract-from "任务描述" \
  --auto-create --json

# 查询品牌
python3 find_brand_profile.py --brand-name "品牌名"

# 更新档案
python3 update_brand_profile.py \
  --brand-name "品牌名" \
  --field "brand_tone" \
  --value "优雅、精致" \
  --json
```

## OpenClaw Skills 加载机制总结

根据本次诊断，OpenClaw 的 skill 加载机制包括：

1. **三层查找顺序**:
   - Workspace-local skills (`workspace-*/skills/`)
   - Global skills (`~/.openclaw/skills/`)
   - Built-in skills (OpenClaw package)

2. **必需文件**:
   - `SKILL.md` - 必需，frontmatter 中 `name:` 必须与目录名一致
   - `metadata.json` - 强烈建议（本次验证）
   - `skill.js` - 可选，但建议包含

3. **配置要求**:
   - `skills.entries.{skill-name}.enabled: true` - 显式启用
   - `agents.list[].skills[]` - agent 级别分配
   - `agents.defaults.skills[]` - 全局默认（可选）
   - `skills.load.extraDirs[]` - 包含 workspace skills 目录

4. **加载状态**:
   - `✓ ready` - 预加载到内存
   - `🚫 excluded` - 按需加载（lazy loading），正常状态
   - `⏸ disabled` - 明确禁用

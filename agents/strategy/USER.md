# USER.md - 关于你的协作者

## 产品虾（Main Agent）

**角色：** 产品研发协调者，你的任务派发者和结果汇总者

**如何与产品虾协作：**
1. 产品虾派发战略任务（附带调研报告）
2. 你基于报告制定战略
3. 你返回战略建议给产品虾汇总

**产品虾的偏好：**
- 战略要有框架（定位/竞争/产品）
- 建议要可执行（短期/中期/长期）
- 避免空泛的战略口号

## 调研专家

**角色：** 你的数据提供者

**如何与调研专家协作：**
- 阅读调研专家的市场报告
- 基于数据制定战略
- 必要时要求补充调研

## 最终用户

**身份：** 快消食品行业从业者（可能是产品经理、品牌负责人、创业者）

**用户需求：**
- 清晰的战略方向
- 可执行的行动建议
- 避免战略陷阱

**如何服务最终用户：**
- 通过产品虾间接服务
- 战略要清晰易懂
- 建议要能落地执行

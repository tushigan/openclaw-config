# OUTPUT_GUIDE.md - 战略专家输出规范

## 一句话原则
**先回正文，再决定是否落文件。绝不能只留空结果。**

## 默认输出格式
对于绝大多数任务，直接用中文结构化输出：

### 1. 总判断
- 先给结论，不绕

### 2. 关键拆解
- 按 3~5 个层次拆清楚

### 3. 风险 / 冲突
- 说清最容易出事的点

### 4. 建议
- 给出可执行建议，不要空话

### 5. 主会话摘要
- 用 3~8 条短句给主会话可直接引用的结论

## 如果任务要求写文件
可以写到 workspace 输出目录，但仍然必须：
- 在 assistant 正文里先给摘要
- 不要只返回路径

## 如果任务只是最小测试
必须直接返回测试文本，例如：
- 当前链路已连通。
- 最小测试通过。

## 禁止
- 空 assistant content
- 只写文件不回结论
- 输出“稍后”“正在处理”作为最终结果

# TOOLS.md - 战略专家工具配置

## 已配置工具

### 数据收集
- `tavily_search` - 网络搜索
- `tavily_extract` - 内容提取
- `browser` - 浏览器自动化

### 数据智能
- `data-intelligence` - Apify 云端爬虫平台

### 文档输出
- `feishu_doc` - 飞书文档撰写

## 工具使用示例

### 竞品战略分析
```
分析竞品的战略定位
→ 使用 tavily_search 收集竞品官网、报道
→ 使用 browser 访问竞品电商页面
→ 提取定位、价格、渠道信息
→ 分析竞争战略
```

### 市场趋势研究
```
研究品类发展趋势
→ 使用 data-intelligence 收集行业报告
→ 分析市场规模、增速、驱动因素
→ 提炼战略机会点
```

### 战略文档撰写
```
输出战略规划报告
→ 使用 feishu_doc 创建文档
→ 结构化呈现战略框架
→ 包含行动建议和时间表
```

## 战略分析工具

### 内部工具
- 调研专家的报告
- 历史战略案例库

### 外部数据源
- 行业报告网站
- 上市公司财报
- 咨询公司研究
- 媒体深度报道

## 注意事项

1. 战略建议要基于可靠数据
2. 避免空泛的战略口号
3. 每个建议都要有行动路径
4. 考虑执行的可行性

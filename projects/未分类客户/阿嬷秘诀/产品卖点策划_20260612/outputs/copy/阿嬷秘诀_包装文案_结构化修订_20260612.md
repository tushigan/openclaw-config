# 阿嬷秘诀｜包装文案结构化修订稿

> 输出日期：2026-06-12  
> 适用对象：卤猪腱、麻笋卤猪腱包装正面信息层级  
> 修订原则：回到包装货架逻辑，以产品名、品类识别、短卖点标签和可落版利益点为核心；情绪表达退后，场景提示只作补充。

---

## 一、整体文案层级建议

1. **产品品名最大**：消费者先看懂“这是什么”。  
2. **核心卖点第二层**：用短标签表达“为什么值得买”。  
3. **形态/口感第三层**：厚切、肉纤维、紧实、入味、笋脆等感官信息。  
4. **3 枚利益点第四层**：短、利、可做徽章或横排标签。  
5. **场景提示最轻**：开袋即食、加餐、佐餐小菜，放在角标或底部小字。

---

# 二、SPU 1：卤猪腱

## 方案 A｜货架识别优先

### 品牌区
- 阿嬷秘诀
- 小字可配：阿嬷秘卤

### 产品品名区
- **卤猪腱**

### 核心卖点区
- **厚切猪腱｜秘卤入味｜肉质紧实**

### 形态/口感区
- 厚切切片
- 看得见肉纤维
- 越嚼越香

### 3枚利益点
- 厚切肉感
- 秘卤入味
- 开袋即食

### 场景/食用提示
- 加餐解馋
- 佐餐小菜

### 背面/侧面说明
猪腱切片经秘卤调味，肉质紧实有嚼劲，开袋即可享用。

### 版面优先级建议
1. **卤猪腱**：正面最大字，占核心视觉记忆位。  
2. **厚切猪腱｜秘卤入味｜肉质紧实**：紧贴品名下方，做成横向标签。  
3. **厚切肉感 / 秘卤入味 / 开袋即食**：三枚徽章化处理。  
4. 场景提示放底部，不抢产品名和卖点。

## 方案 B｜秘卤品牌系统优先

### 品牌区
- 阿嬷秘诀
- 小字可配：阿嬷秘卤肉铺

### 产品品名区
- **卤猪腱**

### 核心卖点区
- **阿嬷秘卤｜猪腱厚切｜卤香入味**

### 形态/口感区
- 厚切猪腱片
- 卤香裹肉香
- 肉质紧实，越嚼越有味

### 3枚利益点
- 阿嬷秘卤
- 猪腱厚切
- 越嚼越香

### 场景/食用提示
- 开袋即食
- 加餐、佐餐都方便

### 背面/侧面说明
来自阿嬷秘卤肉铺的拿手卤味，猪腱厚切入卤，肉香和卤香一起入口。

### 版面优先级建议
1. 品牌区可做“肉铺招牌感”，但面积不宜压过品名。  
2. **卤猪腱**仍为最大识别信息。  
3. “阿嬷秘卤”作为品牌资产标签，放在品名上方或侧边印章位。  
4. 三枚利益点建议做成肉铺小标签，统一包装系统。

# 三、SPU 2：麻笋卤猪腱

## 方案 A｜货架识别优先

### 品牌区
- 阿嬷秘诀
- 小字可配：阿嬷秘卤

### 产品品名区
- **麻笋卤猪腱**

### 核心卖点区
- **猪腱厚切｜麻笋脆爽｜秘卤入味**

### 形态/口感区
- 厚切猪腱片
- 麻笋脆爽
- 肉香配笋香，一口更丰富

### 3枚利益点
- 猪腱肉香
- 麻笋脆爽
- 开袋即食

### 场景/食用提示
- 加餐解馋
- 佐餐小菜

### 背面/侧面说明
厚切猪腱配麻笋，肉香与笋香一起入卤，口感更有层次。

### 版面优先级建议
1. **麻笋卤猪腱**必须完整、大字呈现，避免消费者只记住“麻笋”。  
2. 核心卖点建议用三段式标签：猪腱厚切 / 麻笋脆爽 / 秘卤入味。  
3. 竹绿色或笋片符号可作为口味识别，但不应盖过猪腱主体。  
4. 佐餐提示放底部辅助，不能成为主视觉中心。

---

## 方案 B｜秘卤品牌系统优先

### 品牌区
- 阿嬷秘诀
- 小字可配：阿嬷秘卤肉铺

### 产品品名区
- **麻笋卤猪腱**

### 核心卖点区
- **阿嬷秘卤｜猪腱肉香｜麻笋脆爽**

### 形态/口感区
- 猪腱切片入卤
- 麻笋清脆爽口
- 肉香、笋香、卤香更丰富

### 3枚利益点
- 阿嬷秘卤
- 肉笋双香
- 脆爽入味

### 场景/食用提示
- 开袋即食
- 加餐或佐餐都方便

### 背面/侧面说明
阿嬷秘卤肉铺的猪腱肉香，配上麻笋脆爽，一包吃到更丰富的卤味口感。

### 版面优先级建议
1. 品牌区建立“阿嬷秘卤肉铺”系统，但品名仍居于第一阅读层级。  
2. “阿嬷秘卤”作为系列统一识别，可与卤猪腱款保持同位置。  
3. “猪腱肉香｜麻笋脆爽”是本款差异点，建议靠近品名强化记忆。  
4. 三枚利益点可做成统一小标签，强化系列感。

## 方案 C｜食欲肉感优先

### 品牌区

- 佐餐小菜

### 背面/侧面说明
厚切猪腱搭配脆爽麻笋，肉感更足，口感也更清爽有层次。

### 版面优先级建议
1. 正面仍以**麻笋卤猪腱**为最大信息，避免被“肉笋组合”概念替代。  
2. “厚切猪腱 × 脆爽麻笋”可做核心卖点标签，适合靠近食材图。  
3. 三枚利益点保持短促，便于设计成角标或竖排章。  
4. 场景信息放底部，作为购买后的使用想象，不承担核心说服。

# 四、推荐落版顺序

## 卤猪腱推荐
1. **优先推荐：方案 A｜货架识别优先**  
   理由：产品名清楚、购买理由直接、最适合新品牌在货架上建立品类识别。
2. **备选：方案 B｜秘卤品牌系统优先**  
   理由：更利于系列化和长期品牌资产，但要控制品牌氛围不压过产品名。
3. **辅助：方案 C｜食欲肉感优先**  
   理由：入口欲望更强，适合与切面图或夹起图配合使用。

## 麻笋卤猪腱推荐
1. **优先推荐：方案 A｜货架识别优先**  
   理由：完整呈现“麻笋卤猪腱”，同时讲清猪腱厚切和麻笋脆爽两层价值。
2. **备选：方案 B｜秘卤品牌系统优先**  
   理由：能承接阿嬷秘卤肉铺系统，让麻笋款不脱离主品牌风味资产。
3. **辅助：方案 C｜食欲肉感优先**  
   理由：肉香与笋脆的对比最强，适合强化口感层次和食欲。

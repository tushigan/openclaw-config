## 1. 项目背景

客户此前缺少快消品品牌经验，本项目需要从产品卖点、包装表达和视觉方向开始，逐步建立品牌的消费端表达系统。

本阶段优先解决的问题是：

**如何让消费者在包装上快速理解：阿嬷秘诀不是普通鸭货式卤味，而是有独家秘卤风味、能吃到厚切猪腱肉感的即食卤味产品。**

## 3. 已确认的核心策略

### 3.1 品牌定位判断

阿嬷秘诀不应被定义成“麻酱卤味品牌”，而应定义成：

**有独家秘卤风味的卤猪腱品牌。**

麻酱可以作为识别风味，但不能成为全品牌唯一主轴。真正能统领后续五香、香辣、麻酱、沙茶、藤椒等口味的，是“阿嬷秘诀”里的“秘诀”：独家配方、独特风味、独门手艺。

### 3.2 卤猪腱与鸭货的需求差异

项目中确认了一个关键洞察：

**吃卤猪腱的需求，和吃鸭货的需求不是同一种。**

鸭货偏向：

- 啃食
- 重口刺激
- 追剧零食
- 打发时间

卤猪腱偏向：

- 吃肉感
- 厚切切片
- 肉质紧实
- 开袋即食
- 加餐 / 佐餐补充

因此，阿嬷秘诀不能和鸭货抢“啃食爽感”，而应该建立“厚切猪腱肉感 + 秘卤入味”的产品价值。

## 4. 包装真正要解决的问题

消费者面对新品牌、新产品时有四层阻力：

1. **认知阻力**：阿嬷秘诀是谁？
2. **品类阻力**：卤猪腱和普通卤味有什么不同？
3. **信任阻力**：新品牌敢不敢买？
4. **食欲阻力**：当前内包装和拆开实物颜色深、发黑、发黏，直接看不容易激发食欲。

其中最关键的是：

**食欲阻力 + 认知阻力。**

所以外包装不能直接呈现黑黏内包，而要把真实产品状态转译成：

- 厚切切面
- 肉纤维
- 卤汁光泽
- 肉质紧实
- 秘卤入味

## 7. 文案修订过程中的关键取舍

### 7.1 禁用“真肉”

曾尝试用“真肉”表达肉感，但被判断为不合适。

原因：

**“真肉”会把消费者带入真假肉的错误联想，像此地无银三百两。**

最终替换为更具体的表达：

- 厚切猪腱
- 肉质紧实
- 肉纤维
- 卤香入味
- 厚切切片

### 7.2 删除“越嚼越香”

“越嚼越香”被判断为废话文学，信息增量不足。

最终改为：

**卤香入味**

### 7.3 从 KV 文案改为包装信息结构

一开始的文案结构偏“主标题 / 副标题”，更像海报主 KV。

后续改成包装正面模块：

1. 品牌区
2. 品名区
3. 核心卖点区
4. 利益点
5. 场景提示
6. 背面 / 侧面说明

这更符合包装设计和货架识别逻辑。

## 8. 包装视觉方向

### 8.1 主推方向

**现代秘卤肉铺 × 厚切切面英雄图**

核心画面：

- 厚切卤猪腱切片
- 肉纤维
- 琥珀色卤汁光泽
- 干净现代的秘卤肉铺气质
- 阿嬷秘卤风味章

画面目标：

让消费者 0.1 秒知道：

**这是一包厚切卤猪腱，肉感扎实，卤得入味。**

### 8.2 视觉禁区

- 不直接使用黑黏内包作为包装主视觉。
- 不做老字号、土特产、小作坊感。
- 不大面积用深黑褐，避免显脏。
- 不把麻笋做得比猪腱更抢眼。
- 不让“阿嬷秘卤｜口口好味”风味章抢过品名。

### 8.3 色彩建议

秘制卤猪腱：

- 米杏底
- 酱棕 / 暖红棕肉感
- 朱砂红风味章

秘制麻笋卤猪腱：

- 同体系米杏底
- 酱棕肉感
- 加入竹青绿 / 笋黄作为口味识别

## 12. 阶段性结论

阿嬷秘诀当前最清晰的包装策略是：

**用“阿嬷秘卤”建立品牌风味记忆，用“厚切猪腱切面”建立产品购买理由。**

包装正面不要把消费者带进过度情绪化、过度广告化的表达，而要先完成货架识别：

1. 我是谁：阿嬷秘诀
2. 我是什么：秘制卤猪腱 / 秘制麻笋卤猪腱
3. 为什么买：厚切猪腱、肉质紧实、卤香入味
4. 怎么记住我：阿嬷秘卤｜口口好味

这就是本阶段从策略、文案到视觉形成的统一方向。

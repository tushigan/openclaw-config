# 麦初心语｜蛋糕棒产品线升级项目
## 报价方案框架 v2（整案口径）

### 一、当前确认口径
- 报价类型：项目案
- 项目性质：围绕单一核心产品展开的一套完整升级项目
- 起始阶段：从产品策略开始
- 覆盖范围：产品策略、产品研发建议、产品线规划、渠道策略、包装策划设计、详情页
- 婚庆方向：纳入同一项目主包，但作为一套独立设计体系单独展开
- 价格处理：先不定价，先把结构和边界锁清楚

### 二、项目定义
这不是“做几个包装稿”的设计采购。
而是针对该产品做一轮从上游策略到下游视觉落地的完整项目案。

项目目标是把这个产品从“样品讨论状态”推进到“可销售、可分渠道、可做视觉系统表达”的项目状态。

### 三、建议项目结构

#### 阶段 1：产品策略与研发建议
目的：先定义这个产品到底怎么打，解决什么问题，往什么市场方向走。

建议内容：
1. 现有产品与样品资料梳理
2. 现有问题诊断（口感、造型、品质感、价格带、渠道适配）
3. 产品定位与市场表达方向
4. 产品研发建议
   - 口味方向建议
   - 配方/形态优化建议
   - 规格建议
   - 卖点与记忆点建议
5. 产品线规划建议
   - 核心走量款
   - 风味升级款
   - 渠道专项款
6. 婚庆市场产品方向判断
   - 是否独立命名
   - 是否独立规格
   - 是否独立礼赠表达

建议交付：
- 产品策略梳理文档
- 产品研发建议摘要
- 产品线规划建议
- 婚庆市场产品方向建议

#### 阶段 2：渠道策略规划
目的：明确不同产品组合分别对应哪些渠道，以及每个渠道该怎么讲。

建议内容：
1. 主渠道划分建议
   - 零食系统
   - 鲜食/健康渠道
   - 礼赠/婚庆渠道
   - 其他可选渠道
2. 各渠道产品适配逻辑
3. 各渠道价格带与表达重点建议
4. 婚庆市场的独立渠道逻辑

建议交付：
- 渠道策略梳理
- 产品 × 渠道对应建议
- 婚庆渠道专项建议

#### 阶段 3：包装策划与设计系统
目的：先有包装策划逻辑，再做设计，不走零散改稿路线。

建议内容：
1. 包装母系统策划
2. 品牌语气、命名逻辑、卖点结构建议
3. 不同口味 / 规格 / 渠道的区分机制
4. 对“胶囊感/零食感”的弱化策略
5. 品质感提升的视觉路径
6. 婚庆市场独立包装体系策划
   - 视觉语气
   - 包装形态建议
   - 礼赠属性表达

建议交付：
- 包装策划说明
- 包装系统设计原则
- 婚庆包装体系策划建议

#### 阶段 4：包装设计执行
目的：把前面确认过的策略和策划真正落到具体产品设计稿上。

建议内容：
1. 常规市场首批包装设计
2. 不同口味 / SKU 延展设计
3. 婚庆市场独立包装设计
4. 修改、确认、定稿

建议交付：
- 常规产品包装设计稿
- 延展包装稿
- 婚庆包装设计稿
- 定稿文件

#### 阶段 5：详情页策划与设计
目的：让产品销售表达在线上端能完整承接前面的策略与包装体系。

建议内容：
1. 详情页内容结构策划
2. 卖点叙事与购买逻辑梳理
3. 主详情页视觉设计
4. 婚庆方向详情表达（如需要可独立一版）

建议交付：
- 详情页策划框架
- 详情页设计稿
- 婚庆详情页专项版本（如纳入）

### 四、当前主包建议
建议主报价直接覆盖以下内容：
1. 产品策略与研发建议
2. 产品线规划
3. 渠道策略规划
4. 包装策划与设计系统
5. 常规市场包装设计执行
6. 婚庆市场独立设计体系
7. 详情页策划与设计

### 五、建议后置或单列说明的内容
可单独说明或后续追加：
- 大量打样执行陪跑
- 超出约定数量的新SKU新增
- 展会物料、线下物料、招商物料
- 超范围电商传播物料
- 持续运营类设计

### 六、当前最重要的报价表达方式
报价里要让客户看到：
- 这是一个完整项目，不是单点设计
- 上游会介入产品策略和研发建议
- 中段会做产品线和渠道规划
- 下游会落到包装和详情页
- 婚庆不是附带，而是单独体系纳入主包

### 七、正式报价前还要补的内容
1. 常规市场首批要落地几个包装对象
2. 婚庆市场是否包含独立详情页
3. 每一阶段的修改轮次与确认节点
4. 各阶段最终价格口径

### 八、当前建议
正式报价结构就按这个整案逻辑继续深化。
这个方向已经比较完整，可以作为后续正式报价内容的基础版本。

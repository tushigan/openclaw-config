# 麦初心语｜蛋糕棒产品线升级项目
## 报价方案框架 v3（SPU口径）

### 一、当前确认口径
- 报价类型：项目案
- 项目单位：以单一 SPU 为核心做整案升级
- 起始阶段：从产品策略开始
- 覆盖范围：产品策略、产品研发建议、产品线规划、渠道策略、包装策划设计、详情页
- SKU口径：不预先限定 SKU 数量，因为产品线本身也在本项目内规划
- 婚庆方向：纳入同一项目主包，但作为一套独立设计体系单独展开
- 婚庆详情页：不包含
- 价格处理：先不定价，先锁结构与边界

### 二、项目定义
本项目不是按“几个包装 / 几个 SKU”来拆零报价。
而是围绕一个核心 SPU，完成从上游策略到下游设计落地的一整套升级项目。

也就是说：
- 先定义产品该怎么做
- 再定义产品线怎么规划
- 再定义各渠道怎么打
- 再落到包装系统与详情页表达

### 三、建议项目阶段

#### 阶段 1：产品策略与研发建议
建议内容：
1. 现有产品、样品、会议材料整理
2. 现状问题诊断
3. 产品定位与市场表达方向
4. 产品研发建议
   - 口味方向
   - 配方/形态优化建议
   - 规格建议
   - 卖点与记忆点建议
5. 围绕该 SPU 的产品线规划建议
6. 婚庆市场产品方向判断

建议交付：
- 产品策略梳理文档
- 产品研发建议摘要
- SPU产品线规划建议
- 婚庆方向产品建议

#### 阶段 2：渠道策略规划
建议内容：
1. 主渠道划分建议
2. 各渠道产品适配逻辑
3. 各渠道价格带与表达重点建议
4. 婚庆市场独立渠道逻辑

建议交付：
- 渠道策略梳理
- 产品 × 渠道对应建议
- 婚庆渠道专项建议

#### 阶段 3：包装策划与设计系统
建议内容：
1. 包装母系统策划
2. 命名逻辑、卖点结构、视觉语气建议
3. 不同口味 / 规格 / 渠道的区分机制
4. 弱化胶囊感、提升品质感的表达策略
5. 婚庆市场独立包装体系策划

建议交付：
- 包装策划说明
- 包装系统设计原则
- 婚庆包装体系策划建议

#### 阶段 4：包装设计执行
建议内容：
1. 常规市场包装设计
2. 产品线内相关 SKU / 口味延展设计
3. 婚庆市场独立包装设计
4. 修改、确认、定稿

建议交付：
- 常规市场包装设计稿
- 产品线延展包装稿
- 婚庆包装设计稿
- 定稿文件

#### 阶段 5：详情页策划与设计
建议内容：
1. 详情页内容结构策划
2. 卖点叙事与购买逻辑梳理
3. 主详情页视觉设计

建议交付：
- 详情页策划框架
- 主详情页设计稿

说明：婚庆方向不包含独立详情页。

### 四、主报价建议
主报价直接覆盖：
1. 产品策略与研发建议
2. SPU产品线规划
3. 渠道策略规划
4. 包装策划与设计系统
5. 常规市场包装设计执行
6. 婚庆市场独立设计体系
7. 主详情页策划与设计

### 五、当前关键报价表达
报价里要明确传达：
- 这是按 SPU 做整案，不是按 SKU 计件
- SKU 数量不预先限定，因为产品线规划本身就是项目内容
- 婚庆市场纳入项目主包，但设计体系独立
- 婚庆不含独立详情页

### 六、后续待补内容
1. 修改轮次与确认节点
2. 各阶段价格口径
3. 是否需要补充打样/落地陪跑说明

# 泓一全案服务内容附件（表格版）

| 服务版块 | 分类 | 服务内容 | 说明 / 备注 |
|---|---|---|---|
| 咨询与策略制订 | 企业咨询 | 围绕企业经营发展过程中的战略问题，提供相关咨询支持与方向建议。 | 适用于企业整体层面 |
| 咨询与策略制订 | 品牌咨询 | 围绕品牌发展、品牌架构及品牌表达等事项，提供相关咨询支持与方向建议。 | 适用于三条品牌线 |
| 咨询与策略制订 | 产品咨询 | 围绕产品线规划、产品定位、产品概念及产品表达等事项，提供相关咨询支持与方向建议。 | 适用于产品规划与新品方向 |
| 咨询与策略制订 | 营销咨询 | 围绕营销传播方向、阶段性营销重点及渠道推广节奏等事项，提供相关咨询支持与方向建议。 | 适用于年度及阶段性推广 |
| 咨询与策略制订 | 策略制订 | 围绕企业及三条品牌线的年度发展方向，提供品牌策略、产品策略、营销策略及阶段性专项策略制订支持。 | 为整体项目提供方向依据 |
| 品牌服务 | 企业品牌相关服务 | 企业会议物料策划与设计；企业窗口平面设计；企业简介相关内容策划与设计。 | 企业层面品牌对外表达支持 |
| 品牌服务 | 品牌视觉相关服务 | 品牌 VIS 迭代工作；品牌周边物料设计；日常节点朋友圈传播海报设计。 | 适用于红标、蓝标、wokenday |
| 品牌服务 | 品牌表达相关服务 | 围绕品牌定位、核心价值、卖点提炼及传播表达方向，提供相关梳理与设计支持。 | 强化品牌表达统一性 |
| 产品包装服务 | 产品概念与策划服务 | 产品概念策划及提案；产品卖点梳理；产品线规划建议。 | 适用于新品 / 产品线升级 |
| 产品包装服务 | 产品包装设计服务 | 产品包装设计及制作文件；包装系列化设计规划；产品包装视觉表现设计。 | 适用于产品包装落地 |
| 产品包装服务 | 产品外箱及延展设计服务 | 产品外箱设计及制作文件；包装配套延展设计。 | 适用于渠道流通及配套应用 |
| 产品包装服务 | 包装跟踪与优化服务 | 包装制作跟踪；包装复盘优化。 | 用于后续效果复盘与优化 |
| 终端行销服务 | 终端策划服务 | 终端物料主题策划；阶段性终端推广方向策划；渠道终端陈列表达建议。 | 适用于流通 / 定量 / 私域终端 |
| 终端行销服务 | 终端设计服务 | 终端促销物料设计表现；终端活动相关平面物料设计。 | 适用于终端推广展示 |
| 终端行销服务 | 终端促销支持服务 | 终端促销赠品创意策划；终端促销赠品创意设计表现；落地执行跟踪及复盘优化。 | 支持终端促销转化 |
| 电商与线上详情页服务 | 电商内容策划服务 | 电商主图创意策划；电商产品详情页内容策划；产品卖点逻辑梳理。 | 适用于线上产品表达 |
| 电商与线上详情页服务 | 电商视觉设计服务 | 电商主图创意表现；电商产品详情页设计；产品线上展示相关平面支持。 | 适用于线上渠道展示与转化 |
| 电商与线上详情页服务 | 电商配套支持服务 | 电商产品摄影跟踪；详情页视觉表达方向建议。 | 不含店铺建设及维护运营 |
| 展会服务 | 展会策略服务 | 展厅参展策略；展厅主题及创意策划；展会传播策略及计划。 | 适用于展会整体规划 |
| 展会服务 | 展会设计服务 | 展厅空间设计；空间平面设计；展厅软装、陈列建议、活动等物料策划及设计。 | 适用于展会空间与物料呈现 |
| 展会服务 | 展会传播支持服务 | 展会传播表现；展会前、中、后期相关传播平面支持。 | 适用于展会传播配合 |
| 适用品牌线 | 覆盖范围 | 红标（经典系列）；蓝标（健康系列）；wokenday（唤醒日记）。 | 各品牌线可根据阶段任务匹配执行 |
| 备注说明 | 第三方费用 | 不包含注册费用、视频拍摄、模特、打样制作、场地、投放及其他第三方费用。 | 统一适用 |
| 备注说明 | 设计执行边界 | 企业会议物料、品牌周边物料、终端物料等设计服务，不含打样及制作执行。 | 统一适用 |
| 备注说明 | 企业窗口边界 | 企业窗口平面设计，不含第三方建设及维护运营。 | 统一适用 |
| 备注说明 | 包装边界 | 包装相关服务，不含版权字体、素材购买及印刷执行等。 | 统一适用 |
| 备注说明 | 电商边界 | 电商相关服务，不含店铺建设及维护运营及视频拍摄。 | 统一适用 |
| 备注说明 | 展会边界 | 展会相关服务，不含展厅位置购买、搭建、媒体投放、视频拍摄等。 | 统一适用 |
| 备注说明 | 配合事项 | 需按要求提供拍摄产品；包膜及纸盒等产品可包含一次打样，用于效果方案确认。 | 统一适用 |

# 第1页：标题页

**Wokenday 产品介绍**

打破传统日历的思维桎梏

# 第2页：核心理念

Wokenday 不是「周一到周日」的重复循环

而是一种**全新的时间认知系统**

# 第3页：三大特点

- **自定义周期**：3天、7天、任意天数自由设定
- **专注节奏**：每个 Wokenday 周期都有明确主题
- **打破常规**：摆脱传统星期的束缚

# 第4页：使用场景

**创作者模式**：3天冲刺 + 1天休息

**深度学习**：5天专注 + 2天复盘

**项目管理**：自定义里程碑节奏

# 第5页：设计哲学

时间不是被分配的

时间是被**创造**的

Wokenday 让你成为时间的主人
